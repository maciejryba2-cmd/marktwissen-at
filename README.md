# MarktWissen AT – starter pod 500Affiliates

To jest gotowy statyczny starter strony kierowanej początkowo na Austrię.

## Zanim zgłosisz stronę do 500Affiliates
1. Zmień dane w `impressum.html` i `kontakt.html`.
2. Wstaw wyłącznie materiały marketingowe pobrane z sekcji Marketing Tools na Twoim koncie 500Affiliates.
3. Usuń tekst placeholdera po wstawieniu zatwierdzonego bannera/widgetu/linku.
4. Sprawdź dokładny risk warning wymagany dla rynku austriackiego i użyj wersji zaakceptowanej przez Plus500.
5. Uzupełnij `datenschutz.html` o faktyczny hosting i ewentualne narzędzia cookies/analitykę.
6. Najpierw opublikuj stronę, potem zgłoś URL w panelu 500Affiliates do Compliance.
7. Nie kieruj ruchu do Plus500 z niezatwierdzonych źródeł.

## Darmowy hosting
Najprościej użyć GitHub Pages, Cloudflare Pages albo Netlify. Wszystkie pliki można wrzucić bez systemu CMS.
